Glad to see you here! I'm Muhammad Syukri, a **Data Scientist** with an **MSc in Data Science** from [Coventry University](https://www.coventry.ac.uk/). I build **interpretable machine learning for real-world decisions**, mostly in **sports analytics** ⚽, and I'm also interested in **fintech** problems like fraud detection and risk modelling.

I care most about **honest evaluation**. My models are tested on seasons, competitions or Games they never saw, and I report where they fall short. In each of my main projects, I went back, found flaws in my own first version (like scores measured on training data) and rebuilt it properly.

I'm currently open to **Graduate Data Scientist** and **Analytics** roles in the UK.

### Featured projects

- ⚽ [**Corner Chance Planner**](https://github.com/MSyukri420/final-project-apv): decision support for attacking corners, built on 879 real corners (StatsBomb event data and 360 freeze frames), with a web app for coaches. *Predicts who wins the first ball at AUC 0.68 on unseen competitions.*
- 🧤 [**Serie A Clean Sheet Prediction**](https://github.com/MSyukri420/CleanSheet_Prediction): forecasts clean sheets from each team's last five matches, built with PySpark. *"High" readiness teams kept clean sheets 2.5× more often than "Low" on two unseen seasons.*
- 🏅 [**Olympic Medal Prediction**](https://github.com/MSyukri420/Model_Prediction_Olympic): predicts medals from 271,116 athlete entries (1896–2016), explained with SHAP. *ROC AUC 0.75 on Rio 2016, finding 63% of medallists.*
- 🏢 [**CCK HR Performance System**](https://github.com/MSyukri420/cck-syukri): a full-stack appraisal and survey app built for a real company. *React, Node.js and MongoDB, deployed with one Docker command.*

### Tech stack
